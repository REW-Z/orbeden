# Prefab

Prefab 保存一棵可复用的 Ens 子树。场景中的绑定实例保留来源关系，更新源文件后可以同步节点、组件和属性。

## 创建与放置

将 Ens 从 EnsView 拖到 Project 目录，生成 `.prefab` 文件，原子树成为绑定实例。将 `.prefab` 拖到 Scene 或 EnsView 可以创建新的绑定实例。

绑定节点在 EnsView 中显示浅绿色。实例只允许修改根节点的局部位置、旋转和缩放，也可以整体移动、复制或删除。内部节点、组件和其他属性只读。

系统不支持嵌套绑定。创建新 Prefab 的子树中不能包含其他绑定实例，绑定实例内部也不能插入节点、模型或其他实例；需要独立调整结构时先 Unpack。

普通场景的实例 Inspector 只提供来源、`Edit Prefab` 和 `Unpack`，不提供 Apply 或批量更新操作。源内容在独立编辑模式中修改。

## 编辑源文件

双击 `.prefab`，或在实例 Inspector 点击 `Edit Prefab`，进入独立编辑模式。原场景有未保存修改时使用现有保存、放弃和取消流程。

编辑模式使用纯内存 World，不生成临时 `.world` 文件，不改变启动场景和最后编辑场景。原场景以快照保留在内存中。

已有根节点不能删除或移到其他父级，也不能创建第二个顶层根节点。根节点之下可以正常编辑节点和组件。此模式禁止投放、粘贴其他绑定 Prefab，禁止 Play 和 Player 构建。

编辑栏的 `Apply`、`Return`、`Sync` 三个按钮等宽并排显示。保存会写回源文件；点击 `Apply` 会写回源文件，销毁临时 World，返回原场景并更新其中的实例。点击 `Return` 仅丢弃自最近一次保存后的未保存修改，不回滚此前保存或通过 `Sync` 已提交的内容；本次进入后尚未保存时，Return 丢弃全部临时修改。写回失败时保留现场。关闭窗口时也会尝试写回，失败会取消关闭。

## 更新传播

打开场景时，Editor 读取最新来源并更新绑定实例；没有打开的场景默认不改写磁盘文件。源文件缺失或损坏时保留实例数据和关联，Console 报告错误，可以 Unpack 后独立编辑。

Prefab 编辑栏中的 `Sync` 先保存源文件，再按当前来源扫描项目全部 `.world`。当前普通场景使用内存快照更新，不自动保存其未保存改动；其他引用场景逐文件写入并报告失败。当前场景更新后的撤销历史会清空。

更新保留实例根节点的位置、旋转、缩放、父级和同级位置，其余内容取自来源。已有节点和组件保持稳定身份；新增对象获得新身份；删除对象后，指向它们的引用清空。

## 解绑与撤销

在实例 Inspector 点击 `Unpack`，或在 EnsView 使用 `Unpack Prefab`。选择内部节点时也会解除所属整棵实例的绑定。

解绑保留当前内容、对象身份和引用，文字恢复主题默认状态。解绑、实例化、复制和删除均接入现有撤销与重做流程。

## 场景文件与发布

Editor 场景保存完整实例，在 World 根下附加 `PrefabBindings` 区块。实例来源、根身份和对象映射由 Editor 管理，运行时对象不持有绑定状态。

World Cook 更新实例、清除关联区块，再输出同一种 XML 场景格式。没有绑定实例时不写空关联区块，Cook 按字节复制源文件，Editor 与 Runtime 文件完全一致。来源缺失或损坏会使相关场景 Cook 失败。

在 Project 中移动或重命名源文件时，绑定路径随引用维护流程更新。直接在编辑器外移动文件可能导致来源缺失。

已有无关联对象不会自动识别来源。需要重新创建绑定实例，或将普通子树保存为新的 Prefab。
