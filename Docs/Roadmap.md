# 合批、GPU Instancing、粒子
整改和优化建议：
模拟控制：修正暂停仍积分、停止后自动重播、清空后拖尾槽位未归还。
发射时序：修正 Burst 延迟与循环边界；丢弃的帧时间不能继续积压。
碰撞响应：保留修正后的粒子位置，剩余位移按反弹速度计算。
子发射器：正确应用事件位置、颜色/尺寸/速度继承；修正循环检测和事件预算。
预览隔离：暂停后保留画面；Reset/Stop 不影响其他预览根共享的子发射器。
合批与阴影：批次键剔除对象身份；正确绑定阴影实例 Shader，并补齐 Mesh 粒子阴影。
渲染一致性：补齐 Local 缩放、拖尾渐变/淡出和序列 UV；统一两种绘制路径。
编辑器与持久化：多选只修改被编辑字段；禁止保存运行时状态。
结构精简：合并模拟上下文、配置编解码、反射注册和批次上传；删除空接口及重复逻辑。
构建清理：静态库按工程源文件归档，避免合并文件后残留旧 .obj 被重复打包。
