# Orbeden 游戏开发文档

本目录面向**游戏开发者**：用 Orbeden 做一个游戏需要知道的东西。引擎内部实现、设计取舍与代码约定不在这里——那些在 `Docs/` 下的引擎开发者文档里。

## 怎么读

1. [用户手册](UserManual.md) —— 从创建工程到打包 Player 的完整流程，第一次接触先看这篇。
2. [接口参考](Api/index.md) —— 引擎全部可调用类型与成员的清单，按类型分页。由引擎构建自动生成，不会与代码脱节。
3. 面向开发者但混着引擎实现的文档仍在 `Docs/` 下：[脚本系统](../ScriptSystem.md) 讲脚本编写与宿主机制，[自定义编辑器](../CustomEditors.md) 讲给自己的组件写 Inspector。它们同时涉及引擎内部，因此不随用户文档一起分发。

## 接口参考是怎么来的

`Api/` 由引擎构建时的 `OrbedenDocGen` 生成，数据来自两处：

- **MetaGen 对 C++ 头文件的解析结果**——类型、成员、签名、参数默认值、枚举值，以及头文件里紧贴声明上方的说明注释；
- **托管绑定层的反射结果**——C# 侧真正的类型与成员，包括 `Ens`、`World`、`Resources`、`GUI` 这些手写的托管 API。

**不要手工修改 `Api/` 下的文件**：每个文件首行带生成标记，下一次构建会覆盖它。头文件里的注释是成员说明的来源，想让某个成员在文档里有说明，就在它的声明正上方写一行 `//` 注释。

## 在游戏工程里

创建工程后，这份文档会随 SDK 刷新到 `<工程>/Lib/Docs/`。那是引擎的地盘，和 `Lib/` 下的其他 SDK 快照一样由构建整块刷新。**自己的笔记请放进 `Content/` 下**，那里是你的地盘。
