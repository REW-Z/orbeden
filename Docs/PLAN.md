# Editor 重构与 World 加载扩展

## 1. 总体方案

- 所有 Panel 类迁至 C#，统一继承 `EditorPanel`；C++ 保留渲染、拾取、物理、序列化及平台窗口服务。
- Scene 工作区改为普通 Panel，通过纹理显示原生渲染结果，支持停靠与独立 GLFW 窗口。
- 新增独立预制体资产、跨 Panel 引用赋值、World 创建与切换。
- 保持 C++ UTF-8 和现有字符串桥接，本次不做编码优化。
- 遵循项目规范和 `rew_style`；保留工作区已有修改，移除被新方案替代的 Editor 实现。

## 2. Panel、窗口与场景视图

### 统一 Panel 体系

- `EditorPanel` 提供统一绘制入口，负责主题应用、内容边距、标题栏与关闭按钮；子类只实现内容和必要生命周期。
- C# `PanelManager` 统一管理注册、可见性、Dock 树、标签页和布局持久化。迁移 EnsView、BuildGame、Dev，新增 ScenePanel。
- 共享 `EditorTheme` 统一定义颜色、尺寸及间距，修改后作用于所有窗口；本次不新增主题编辑器。
- 关闭 Panel 仅隐藏，通过窗口菜单重新打开。迁移和合并窗口保留 Panel 实例、选择与滚动状态。

### 停靠与独立窗口

- 主窗口中拖动标签栏支持合并标签页、四边拆分与停靠预览；拖出主窗口自动创建承载该 Panel 的 GLFW 窗口。
- 独立窗口使用系统标题栏和关闭按钮，内部不重复绘制 Panel 外壳。
- 支持拖动系统标题栏回主窗口停靠；同时提供统一的“合并回主窗口”菜单，优先恢复原停靠组，原组不存在则使用默认位置。
- 当前 Windows Editor 使用原生窗口移动事件处理标题栏拖动；相关代码封装在平台桥接中。
- 每个 GLFW 窗口拥有独立 ImGui 上下文及绘制状态，OpenGL 上下文共享纹理。绘制后恢复主上下文。
- 跨窗口拖拽由编辑器统一维护载荷和屏幕坐标，不依赖不同 ImGui 上下文之间自动传递载荷。
- 保存停靠布局、浮窗位置尺寸及可见性；恢复时将离屏窗口移回可用显示区域。主窗口退出统一清理浮窗。

### ScenePanel

- 使用现有 RenderTarget 能力，将编辑相机输出改为离屏纹理，按内容区像素尺寸与 DPI 调整。
- 拾取、Gizmo、选中轮廓和拖放统一使用 Scene 内容区坐标，并正确裁剪；不读回整幅图像到 CPU。
- Scene 隐藏或最小化时暂停其视口渲染，恢复后重建必要资源。
- 保留现有 Play 行为：隐藏全部 Panel 及浮窗，在主窗口显示游戏；停止后恢复编辑 World、相机与布局。本次不新增 GamePanel。

## 3. Project、引用框与预制体

### ProjectPanel

- 左侧目录树、右侧选中目录的直接子目录及资产列表，两侧独立滚动，分隔位置可调整。
- 搜索限定当前目录；保留导入、重命名、移动、复制、删除、外部文件变化监听和右键扩展。
- 文件夹拖放移动复用现有资产操作及引用路径更新，拒绝移入自身子目录。
- 增加创建 World、设置启动 World，以及接收 Ens 拖入保存预制体。
- 不增加缩略图网格或全项目搜索。

### 引用框与拖拽

- 替换引用字段的下拉框，统一覆盖原生及 C# 的 Ens、Component、资源引用。
- 引用框显示名称、类型和空值／丢失状态，支持清空、点击定位、搜索选择器及类型过滤；枚举字段继续使用下拉框。
- 补齐字段声明类型的元数据传递，不依靠字段名称判断引用类型。
- Ens 拖入 Component 字段时按声明类型匹配：单个候选直接赋值，多个候选弹出选择，无匹配则拒绝。
- Project 资产按资源类型赋值；场景引用不能写入独立资产。
- 悬停仅显示预览，释放后提交修改，接入现有撤销／重做和 Dirty 标记。
- 拖拽载荷携带资产 key 或对象身份及 World 会话标识；切换 World、删除源对象、关闭源窗口时取消失效拖拽。

### 独立预制体

- 新增 `.prefab`，保存一个根 Ens、全部子级、组件及持久化字段，复用 World 序列化规则。
- Ens 拖到 Project 当前目录或目录节点即可保存；重名生成不冲突名称。
- 参考已检查的 Unity 源码：保留资产引用，重映射内部引用，将文件中的外部场景引用写为空，不修改源场景对象。
- 实例化时为所有 Ens 和组件生成新身份，再重映射内部引用，保留层级与组件顺序。
- 拖到层级节点沿用现有前／后／子级投放规则；空白处创建根实例，保留预制体局部变换。
- 拖到 Scene 优先使用鼠标命中表面位置，其次使用世界地面 `Y=0` 交点，均无交点时放在相机前方 10 个世界单位；仅调整根位置。
- 实例化作为一次撤销操作；失败清理未完成实例，不留下部分子树。
- 本次只有 `.prefab` 可拖入场景创建实例，不实现模型自动建 Ens、源修改传播、实例覆盖或嵌套预制体关系。

## 4. World 创建、切换与加载接口

### 编辑器行为

- 在 Project 当前目录创建空 `.world`，使用默认 RenderSettings，不写入编辑器相机；创建后打开。
- 双击 World 切换；存在未保存修改时提供“保存／放弃／取消”，保存失败或取消时保持当前 World。
- 启动 World 独立于当前编辑 World，继续使用 `.oeproj` 的 `startupWorld`；右键设置后持久化并显示标记。
- 移动或重命名 World 时同步更新配置引用；删除启动 World 前要求先指定替代项。
- 编辑器 Play 从当前编辑 World 开始，独立 Player 从启动 World 开始。运行时 World 切换不改写编辑器的当前文件及启动配置。
- World 成功切换后清理选择、撤销历史和旧引用选择器状态。

### API 与加载状态

- C# 新增 `World.Load(key)`、`World.LoadAsync(key)`，统一返回 `WorldLoadOperation`。
- 操作对象提供 `State`、`IsDone`、`Succeeded`、`Error`；状态包含准备中、等待提交、提交中、成功、失败和取消。
- C++ 由 `Application` 持有加载请求与结果，提供对应同步／异步入口；仓库调用方同步更新。
- 对外 key 相对 Content 根。一次只允许一个加载请求，重复请求返回明确的忙碌失败，不覆盖已有请求。
- 同步加载在回调外完成提交后返回；生命周期回调内同步完成准备，回调结束后在安全点提交，返回的操作仍可处于等待提交状态。
- 异步仅将文件读取、解析与纯数据校验放到后台；资源加载、对象准备及生命周期处理在主线程执行，提交阶段允许短暂卡顿。本次不提供百分比进度或公开取消接口。

### 切换与失败处理

- 拆分现有“清空后解析”流程，先完整准备目标数据和资源，再提交替换。
- 主线程准备未激活的目标对象；准备期间不发布到当前 World 查询，也不触发挂载、脚本或物理注册。失败时释放准备对象，旧 World 保持原样。
- 准备对象使用独立身份映射，处理重载同一 World 时与旧稳定 ID 冲突的问题；新 EnsId 必须避免重新命中旧句柄。
- 提交前完成可报告的加载校验；在安全点结束旧脚本生命周期、释放旧内容、安装目标内容，再启动新 World 生命周期。
- 保持 `Application` 对外 World 容器稳定，更新对象、组件存储及系统归属，避免系统持有悬空 World 指针。
- 新 World 激活后的用户脚本异常按运行时异常处理，不作为文件加载失败回滚。
- 退出、项目关闭、停止 Play 或模块卸载时终止未提交请求并等待后台任务收尾；不向已销毁脚本派发完成回调。
- Play 中切换 World 后，停止仍恢复进入 Play 前的编辑 World。

## 5. 验证与交付

- **窗口：** 所有 Panel 的外观、关闭重开、标签合并、拆分、拖出、标题栏拖回、菜单合并、跨显示器 DPI、布局恢复及退出清理。
- **场景：** 停靠／浮动／缩放后画面比例、拾取、Gizmo、轮廓和落点一致；Play 前后 World 与布局正确恢复。
- **引用：** 原生与 C# 字段、派生类型、多组件候选、错误类型、清空、丢失引用、跨窗口拖放及撤销／重做。
- **预制体：** 子树与字段往返、内部循环引用、外部场景引用清空、多次实例化身份隔离、失败无残留。
- **World：** 同步与异步切换、回调内安全提交、重复请求、缺失／损坏文件、未知组件、资源加载失败、旧句柄失效及停止 Play 恢复。
- **回归：** 现有资产操作、组件编辑、脚本热重载及 Player 启动流程；增加必要的序列化与加载生命周期测试，窗口交互进行实际运行验证。
- 更新原生项目文件、文档及受影响的项目版本；通过正式生成流程刷新绑定和 SDK，不手改生成文件。构建验证在实施阶段执行。
