# 欢迎工作区

未打开游戏项目时，编辑器默认在整个工作区显示 C# `WelcomePanel : EditorPanel`。此时不显示空 Scene、Inspector 或 Play 工具栏。打开项目后自动恢复该项目的停靠布局，欢迎页不写入项目布局，也不能从 Views 菜单切换到普通停靠窗口。

欢迎页提供“打开项目”和“新建项目”入口，以及最多 24 个最近访问项目，按最近打开时间排序。卡片显示项目名称、完整目录和最后编辑时间。单击卡片会排队到下一次帧更新时直接打开对应 `.oeproj`，不在托管绘制回调内部切换世界或卸载程序集。项目版本不匹配时继续走现有升级或拒绝加载流程。

最后编辑时间来自 `Content` 目录及其内容文件的最后修改时间，后台读取，不把项目访问、构建输出或资源缓存时间误当成内容编辑时间。项目没有 Content 目录时使用项目文件创建时间。时间按本机时区显示；可用 Refresh 更新。失效路径显示为不可打开状态，右键“Remove from recent projects”只移除历史记录，不删除磁盘文件。

历史存放在当前用户的 `%LOCALAPPDATA%/Orbeden/Editor/recent-projects.json`，以临时文件替换方式保存。记录覆盖菜单打开、新建项目和欢迎页打开，从此功能启用后开始累积，不扫描磁盘猜测此前访问过哪些项目。历史文件不可读或不可写时，欢迎页展示错误但仍可打开或新建项目。
